Shrink games

# 1.Cube Stack
A tiny stacking game made with HTML Canvas and JavaScript.
Place each moving block on top of the last one. Miss the stack and the game resets.

## Controls
- Click / Tap
- Space
- Arrow Up
- W

## Built With
- HTML
- JavaScript
- Canvas API
- Web Audio API
